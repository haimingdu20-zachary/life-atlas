# 人生地图 · Life Atlas

一个本地优先的个人生命记录应用：从 3D 地球放大到城市与区县，点击大致位置后记录亲身经历，并可让 AI 在不编造事实的前提下帮你完善叙述。

维护仓库：[haimingdu20-zachary/life-atlas](https://github.com/haimingdu20-zachary/life-atlas)。在已有本地版本上加入轻量的旅行回顾功能，保留原有地图、编辑器和人生时间线。

## 在线使用

访问 [人生地图](https://haiming-life-atlas.haimingdu20.chatgpt.site)，使用站点所有者的 ChatGPT 账号登录。手机浏览器和电脑使用同一个账号访问，即可读取同一份线上记录。站点当前仅所有者可用。

线上使用独立的 D1 数据库保存记录、R2 保存上传文件，与电脑里的 `.wrangler/` 数据分开。第一次进入线上版是空白地图，本机记录不会自动上传。AI 润色可在“AI 接口”中自行配置 OpenAI 或 DeepSeek；未配置密钥时仍可使用基础文字整理。

## 这个版本新增的两件小事

1. **按年份回看足迹**：打开“我的经历”，选择年份，也可以叠加地点、标题或标签搜索。地图标记与列表一起筛选，显示当前经历数和地点数；关闭面板后仍有筛选提示，可以一键恢复全部足迹。年份按经历开始时间、设备本地时区计算；“地点数”按记录中的地点名称去重，不代表城市数或旅行次数。
2. **导出旅行手记**：点击“导出旅行手记”，把当前筛选结果按时间先后下载为 Markdown 文件，包括日期、地点、人物、摘要、叙事、保留的原文、感悟和标签。导出在浏览器本地完成，不需要 AI Key；文件仅含文字，不含照片、音视频、账号凭据，也不是可恢复的完整数据备份。可以用 Markdown 编辑器打开，也可以作为纯文本保存。

## 已实现

- 地球与地图合并为一个 MapLibre 模块，远看是球体，放大后进入城市/区县地图
- 搜索城市或区县、点击地图、或使用设备当前位置
- 点击已有坐标查看经历，并可新建、编辑、删除和检索记录
- 记录时间、类型、人物、原始片段、完整叙事、摘要、感悟和标签
- 无 API Key 时提供本地智能整理（断句、分段、去重、摘要和标签）；配置 Key 后自动升级为 OpenAI 润色
- 双栏记忆工作台：左侧记录与逐项接受整理建议，右侧固定显示地图位置、记忆卡和照片时间线预览
- 30 秒快速记录与完整经历两种模式，支持原文保留、情绪、人物、人生章节、标签和私密等级
- 照片、视频、语音与文件保存到本地 R2 对象存储；照片可读取拍摄时间和位置
- 草稿自动保存和离开保护，默认仅自己可见
- 人生主线 XY 时间轴：X 轴是时间，Y 轴是不同主线，支持进度、下一步和关联经历节点
- 项目内本地 D1/SQLite 持久化，刷新和重启后仍保留经历

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
git clone https://github.com/haimingdu20-zachary/life-atlas.git
cd life-atlas
npm ci
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000)。本地数据保存在项目的 `.wrangler/` 目录，该目录已被 Git 忽略。

## 可选：将本地整理升级为 OpenAI 完善

可直接点击地图右上角的“AI API 设置”，选择 OpenAI 或 DeepSeek，输入对应 API Key、模型 ID 并测试连接。两家的凭据分开保存；DeepSeek Responses API 默认使用 `deepseek-v4-flash`。默认只保存在当前浏览器会话；只有主动勾选后才会记住在此设备。API Key 不会写入人生记录数据库。

也可继续使用 `.env` 方式：

将 `.env.example` 复制为 `.env`，填入自己的 OpenAI API Key：

```bash
OPENAI_API_KEY=your_key_here
OPENAI_MODEL=gpt-5.4-mini
```

然后重启 `npm run dev`。未配置时功能仍可用，并且内容不离开电脑。配置后，密钥只在本地服务端使用，不会发送到浏览器；点击完善时，当前草稿会发送到 OpenAI Responses API 进行处理。

## 数据说明

首次启动会放入几条可直接查看的演示经历，可以在界面内删除它们。

内置 Natural Earth 国家边界与主要城市数据，离线时仍可查看地球和查询大致地点；详细地图使用 OpenFreeMap/OpenStreetMap，卫星影像使用 EOX，在线地点名称查询使用 Nominatim。这些在线服务需要联网，不需要 Mapbox Token。离线数据不能替代街道或区县级地图。

`.wrangler/` 内包含本机数据库与媒体文件。迁移完整数据时，先停止服务，再另行备份整个目录；GitHub 仓库仅保存源码，不包含你的旅行记录、上传文件、API Key 或本地压缩包。已初始化的数据不会因为更新源码而被重置。

## 运行范围

这是一个带服务端接口、SQLite/D1 与对象存储的应用，不能直接作为 GitHub Pages 静态网站运行。GitHub 提供代码下载，也可以按上述步骤在本地启动。`.openai/hosting.json` 已关联本仓库的独立 Sites 站点；推送 GitHub 不会自动更新线上站点，需要另行发布。生产数据库由 `drizzle/` 迁移建立，运行时不执行本地演示数据初始化。
